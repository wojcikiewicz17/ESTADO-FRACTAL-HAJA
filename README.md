# ESTADO-FRACTAL-HAJA

Projeto documental e técnico com cinco camadas explícitas:
1. obra autoral protegida;
2. manifesto simbólico;
3. protocolo técnico verificável;
4. base jurídica comparada;
5. limites legais.

## Escopo
Este repositório é uma base pública de integridade documental, governança e estudo jurídico-comparado.
Não constitui, por si só, reconhecimento estatal, tratado internacional automaticamente válido, personalidade internacional plena ou soberania jurídica real.

## O que o `HAJA.SH` faz
- valida a presença de documentos obrigatórios (`--check`);
- regenera a carta-semente (`--generate`);
- gera hashes e cadeia de custódia local (`--hash`);
- verifica integridade por comparação de hash (`--verify`);
- pode emitir saída JSON (`--json`) para integração CI.

## Integridade por hash
Hash SHA-256 comprova integridade de conteúdo em um ponto temporal (com UTC e versionamento).
Hash não prova automaticamente autoria exclusiva, validade jurídica automática ou veracidade material de fatos.

## Direitos autorais e Berna
A Convenção de Berna protege automaticamente a forma de expressão autoral sem formalidade.
Não protege ideias abstratas, métodos em si ou fatos brutos sem originalidade expressiva.

## Estrutura documental
- `LEGAL_BASIS.md`: normas aplicáveis e referência comparada.
- `SUMULAS_E_JURISPRUDENCIA.md`: precedentes e aplicação no contexto do projeto.
- `CHILD_DATA_PROTECTION.md`: política técnica-jurídica para dados infantojuvenis.
- `LIMITS_AND_DISCLAIMER.md`: limites legais e ausência de promessas absolutas.
- `HASHES.md`: inventário de integridade por arquivo.

## Limites jurídicos
- GitHub não substitui registro formal; funciona como trilha temporal/versionada adicional.
- Publicidade do repositório não equivale a cessão ao domínio público.
- Qualquer uso de dados pessoais, especialmente de crianças e adolescentes, exige base legal aplicável, necessidade, finalidade e proteção adequada.
- Termos simbólicos, constitucionais ou institucionais são tratados neste repositório em caráter declaratório, acadêmico e experimental.
