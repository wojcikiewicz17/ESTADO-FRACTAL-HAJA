# CONTRIBUTING

## Requisitos para contribuição
- Preservar conteúdo legado (mover para `docs/legacy/` quando reestruturar).
- Não misturar licença com manifesto no mesmo arquivo normativo.
- Não inserir dados pessoais reais de crianças/adolescentes.
- Executar antes de abrir PR:
  - `./HAJA.SH --check`
  - `./HAJA.SH --generate`
  - `./HAJA.SH --hash`
  - `./HAJA.SH --verify`

## Padrão de commit
Commits pequenos, atômicos e com mensagem clara.
